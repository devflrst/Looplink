# LoopLink

Static PeerJS snake game for GitHub Pages.

## Run locally

Open `index.html` directly in a browser or serve the folder with a static server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000/

## Deploy to GitHub Pages

1. Push this folder to the repository.
2. In GitHub, enable GitHub Pages from the repository settings.
3. Select the root folder or the branch you want to publish.

This project is designed for static hosting and does not require a backend server.
